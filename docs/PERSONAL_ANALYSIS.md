# 行情分析助手 V0.3.1

本版围绕图上关注位置，呈现高周期背景、反应区、流动性参考、局部确认与订单流。先整理证据，再手动请求 AI 解释同一份冻结快照。它是带证据的分析工具，尚未完成个人交易规则校准、训练或收益验证。

## 默认参考原则

V0.3.1 移除独立「我的看盘规则」页面、导航和参数 / 目标填写表。日常流程为图上选关注位置、等待到区、查看分析、记录交易与复盘；无需先配置规则。新分析固定使用默认参数，旧页面保存的参数、备注和路线不会影响当前解读，历史记录不删除。

后台保留来自 Lecture 034、001、010 二次笔记的八条参考原则及文件哈希、时间锚点。原始视频和图表未独立核验；固定摆动、清扫、位移和 FVG 仍只是参考候选，不能自动证明个人有效 MSB 或 Primary Target。AI 引用这些原则时在当前分析中展开说明。

当前页面呈现高周期背景、反应区、流动性参考、局部确认与订单流。内部快照仍保留目标缺失等状态，以明确盘面解释不能自动构成完整交易计划。V0.3.0 的旧参数、人工路线与终止证据保留供历史审查；独立路线后台监控已停用。

## 图上证据

分析区域、关注区及局部反应保存独立证据 ID、周期、价格范围、发生与已知时间。点击定位会切换周期并显示临时分析证据，不新增绘图、不重启已消费 OB/FVG。窗口数值、目标状态与规则引用另有快照说明。

## 千问 AI 平台

连接设置使用用户指定的千问 AI 平台，固定服务地址 `https://maas.qianwenaiapi.com/compatible-mode/v1/`，服务端发送 Bearer Key。Key 使用本机 Data Protection 加密；Windows 密钥环由当前用户 DPAPI 保护。也支持 `Qianwen__ApiKey` 环境配置。Key 不回显、不进入分析输入或导出，私人数据库不上传 GitHub。

可选模型为 `qwen3.8-max`、`qwen3.8-max-0902`、`deepseek-v4-pro-0813`、`qwen3.5-omni-plus`。两个 Max 模型使用严格 JSON Schema；其他两个使用 JSON Object 并在服务端校验结构与引用。文本请求关闭千问思考，Omni 使用 `max_tokens`，其他模型使用 `max_completion_tokens`；解释最多 2,304 输出 token，连接验证最多 64。真实联网测试以验证记录中的模型为准，离线适配器测试不代表所有模型账号权限都已验证。

只有点击「AI 解释当前快照」才产生模型请求；后台盯盘不自动调用模型。输入包含行情窗口、默认参考原则、图上关注区、步骤、证据与缺失信息，不上传交易手记或账户数据。导出保存模型名称、快照 ID、生成时间、输入/输出 token 和引用。

返回分为盘面解释、支持、冲突/缺失与下一步观察条件。截断回复、陌生字段、未知证据 ID 或快照错配会被拒绝。引用校验保证 ID 存在，不能证明模型每句话都正确；个人仍需结合图表复核。数据缺失不补造，OI 增加不识别多空，价量反向不直接证明吸收，OI 下降不直接证明清算；不据此自动下单或生成完整 setup。
