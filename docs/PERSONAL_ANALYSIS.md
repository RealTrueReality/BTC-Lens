# 个人分析助手 V0.3.0

本版把个人看盘流程整理成可检查的六步：高周期背景、反应区、流动性参考、局部确认、订单流、目标。规则层先计算状态，用户再手动请求 AI 解释同一份冻结快照。它是带证据的分析工具，尚未完成个人交易规则校准、训练或收益验证。

## 规则卡与来源

`/playbook` 有八张规则卡，来自用户提供的 Lecture 034、001、010 笔记：目标与反应区的角色、高低周期、清扫与交付、冲突、新路线、有效结构与回收。卡片记录笔记文件名、SHA-256、对应段落和视频时间锚点。Lecture 034 文件哈希为 `004349677d50362fd3389f59ebbc9ca75d52d6b808e6d7f701cbaae40f137784`。

这些笔记属于二次整理，原始视频画面和讲解未独立核验，默认全部待复核。个人复核、备注与参数变更保存新版本；默认左右两根摆动、20 根清扫回看、5m 局部周期，以及整理价格、成交差、OI 的阈值。位移和新 FVG 只能加强参考候选，不能自动证明个人有效 MSB。没有把未触碰 FVG 自动升级为 Primary Target。

## 人工观察路线

用户可保存观察方向、目标、失效参考、来源理由及目标角色复核。保存要求新鲜报价、目标与失效方向合理，记录选择时间和版本。它是人工观察目标，不自动具备正式 Primary Target 来源资格；事后选择不能追认更早的结构确认。

消费与失效使用选择后已知的报价及完整收盘数据判定。时间顺序明确时先发生的终止条件生效；选择所在 K 线或同时条件存在歧义时保留未定，缺少历史不能声称目标仍开放。生产后台保留已观测的终止状态，重启或随后回撤不会恢复旧路线；新判断需要新的观察路线版本。轮询与报价采样仍可能漏过短暂触及。

## 图上证据

分析区域、局部反应及人工目标保存独立证据 ID、周期、价格范围、发生与已知时间。点击定位会切换周期并显示临时分析证据，不新增绘图、不重启已消费 OB/FVG。窗口数值、目标状态与规则引用另有快照说明。

## 千问 AI 平台

连接设置使用用户指定的千问 AI 平台，固定服务地址 `https://maas.qianwenaiapi.com/compatible-mode/v1/`，服务端发送 Bearer Key。Key 使用本机 Data Protection 加密；Windows 密钥环由当前用户 DPAPI 保护。也支持 `Qianwen__ApiKey` 环境配置。Key 不回显、不进入分析输入或导出，私人数据库不上传 GitHub。

可选模型为 `qwen3.8-max`、`qwen3.8-max-0902`、`deepseek-v4-pro-0813`、`qwen3.5-omni-plus`。两个 Max 模型使用严格 JSON Schema；其他两个使用 JSON Object 并在服务端校验结构与引用。文本请求关闭千问思考，Omni 使用 `max_tokens`，其他模型使用 `max_completion_tokens`；解释最多 2,304 输出 token，连接验证最多 64。真实联网测试以验证记录中的模型为准，离线适配器测试不代表所有模型账号权限都已验证。

只有点击「AI 解释当前快照」才产生模型请求；后台盯盘不自动调用模型。输入包含行情窗口、规则卡、个人规则备注、观察路线、步骤、证据与缺失信息，不上传交易手记或账户数据。导出保存模型名称、快照 ID、生成时间、输入/输出 token 和引用。

返回分为盘面解释、支持、冲突/缺失与下一步观察条件。截断回复、陌生字段、未知证据 ID 或快照错配会被拒绝。引用校验保证 ID 存在，不能证明模型每句话都正确；个人仍需结合图表复核。数据缺失不补造，OI 增加不识别多空，价量反向不直接证明吸收，OI 下降不直接证明清算；不据此自动下单或生成完整 setup。
