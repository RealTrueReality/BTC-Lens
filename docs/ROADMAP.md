# 后续迭代

## V0.1：当前首版

- 公共行情与前缀回放。
- 已确认的自有 FVG/参考 OB、关键价格。
- 自动区域转关注、手动选区、版本。
- 首次到区去重、不可变证据。
- 交易、截图、复盘、成本明确的统计。
- CSV 预览、事务导入、分析 JSON 导出。

## V0.2：订单流采集（已实现）

- 现货/永续公共主动成交与 BTC 单位 CVD。
- 永续 OI 原生张数、BTC、USD。
- 每秒事务保存、重复与乱序检查、重连和重启分段。
- 三个订单流图表窗格，1m/5m/15m 采样显示。
- 分段记录、局部原始成交导出、观察与交易快照。

## V0.2.1：多周期价格与成交量参考（已实现）

1. 图上手选固定范围，保存 VAH/POC/VAL、原始 5m K 线、合约元数据与来源摘要；近似分配和覆盖状态可见。
2. 当前日/周/月 VWAP，固定 5m HLC3 与 BTC 数量；UTC/UTC+8 重置，周一及日历月边界明确。
3. 独立历史分页和持久化缓存，补齐周/月锚点；关注区、报告、事件与交易记录联动。

## V0.2.2：实时图表工作区（已实现）

- 只保留实时行情，移除宣传文案与演示入口。
- 在图上点击 OB / FVG 加入关注，矩形、水平线、趋势线可绘制、拖动、保存、定位和删除。
- 矩形转关注区在同一事务完成，图上保留一个对象；旧版本证据不改写。
- 多个固定范围成交量分布同时显示，各自定位、隐藏和删除。

## V0.2.3：历史选区补取（已实现）

- 移除 40 天限制；从所选范围终点分页，只请求缺失的历史。
- 缓存索引、加载进度、取消与续传；实时行情继续更新。
- 不完整预览需要明确确认才保存；冻结数据支持当前周期图中定位。

## V0.2.4：趋势线关注与免费订单流汇总（已实现）

- 趋势线动态关注带，按端点斜率向未来延伸；首次靠近或连续穿越记录，保存实际动态边界。
- 免费 OKX + Binance 现货/永续公共成交，独立连接、去重、重连与采集段。
- 共同完整分钟累计 CVD，BTC/USDT、Delta、时间范围和交易所控制；价格/CVD/OI 共用时间轴和光标。
- 研究 Coinalyze 免费历史 API；V0.2.4 本身没有回补此前未采集的订单流，接入在下一版本实现。

## V0.2.5：Coinalyze 与行情解读（已实现；真实提供方联调待 Key）

- 免费 Key 本机设置、验证、加密保存与移除；可选市场和预算明确。
- 所选多交易所已收盘买卖量与线性永续原生 BTC OI，90 秒刷新，缺口不填零。
- 15m / 1h 价格、成交差与 OI 对齐，结合附近 OB/FVG/关注区、日线/4H 背景、参考回收 / N2 破位、VWAP / 完整分布。
- 输出行情特征、支持/冲突、缺失与后续条件；冻结并导出本次解读。
- 当前为明确版本的规则解释；尚未配置大模型、训练个人规则或完成 Coinalyze 真账户联调。

下一轮：用户 Key 联调与提供方原生单位抽样对照；个人规则卡、EQH/EQL、Sweep、SFP、BPR，先审核个人规则与确认延迟。

验收：数据缺口可见，历史 cutoff 重放无未来数据，人工标注对照可复核。实际日期取决于历史成交可得性与规则审核。
