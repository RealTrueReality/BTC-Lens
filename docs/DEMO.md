# 三分钟核心闭环演示提纲

`demo.webm` 对应 V0.1 核心闭环；`price-context-demo.webm` 展示 V0.2.1 的 VWAP、图上时间选区、成交量分布、加入关注和观察报告，使用合成行情。可运行 `node tools/record-price-context.cjs` 在独立测试实例重新录制。

## 0:00–0:30：真实使用动机

“我平时会先看日线和 4H 的区域，再等低周期反应。这个项目把重复观察、关注区和交易复盘放到同一处。”

展示技术栈和演示标识。说明默认数据是合成回放，便于稳定重现流程。

## 0:30–1:10：行情与关注

- 展示 K 线、周期切换、FVG/参考 OB。
- 从自动区域加入关注，编辑边界和关注原因。
- 说明自动参考算法与个人选择分别保存。
- 可以展示图上两点选区。

## 1:10–1:40：提醒与版本

- 新回放后推进五根，出现一次到区事件。
- 查看原关注版本、触发价格和证据。
- 再推进/刷新，说明去重。
- 编辑关注区后，旧事件仍保留原边界。

## 1:40–2:20：交易与复盘

- 从提醒进入交易手记。
- 录入实际价格、数量、初始止损、成本和复盘。
- 展示截图与来源事件。
- 说明缺失费用不会自动当成零，初始风险保存后固定。

## 2:20–2:50：工程能力

- 简要展示分层结构。
- 介绍后台订阅、REST 兜底、SQLite 持久化。
- 展示测试：确认时间、事务、重复导入、重启一致性。
- 展示 CSV 预览与导入。
- V0.2：展示现货/永续 CVD 与 OI；指出采集起点、原生单位和缺口记录，打开一段聚合成交导出。

## 2:50–3:00：下一步

“现货/永续 CVD 和 OI 已接入。下一步补充固定范围成交量分布、VWAP 与个人规则，让分析报告逐步接近我的实际看盘流程。”

面试时可以称为个人项目，不把合成统计描述为真实收益或商业金融系统经验。
