# 首版规则与数据口径

所有规则属于 BTC Lens 独立参考检测器；不改写历史课程 Playbook。

## FVG

输入必须是同一品种、周期的有效 OHLCV。先筛选 Confirmed=true 且 CloseTime<=Cutoff，再按 OpenTime 去重排序。

连续 A、B、C：

- Bullish：C.Low>A.High，区间 [A.High,C.Low]。
- Bearish：C.High<A.Low，区间 [C.High,A.Low]。
- 等号不构成缺口；C.CloseTime 是理论确认时间。实际程序只在收到确认数据后生成。
- 创建该区域的 K 线不用于回访判断。
- 后续已收盘 K 线高低范围与区域相交时 Touched。
- 看涨区域的后续 Low<=Lower 或看跌区域的 High>=Upper 时 Filled，记录该 K 线收盘时间。
- 生命周期事件时间是收盘确认时间，不声称知道蜡烛内部的精确触及秒数。

## Reference OB

默认 pivotSize=5，严格高/低于左右邻居，价格相等的摆动点不确认。

- 每根 K 线只能使用已经由右侧五根确认的摆动点。
- 看涨突破：当前 Close>最近确认高点，前一 Close<=该点。
- 看跌突破：当前 Close<最近确认低点，前一 Close>=该点。
- 从突破前一根反向搜索至该摆动点，找最后一根反向实体 K 线；找不到则不生成。
- 使用源 K 线完整 High/Low，确认时间为突破 K 线收盘。
- 每个摆动点、方向只消耗一次。
- 看涨 OB 后续 Close<Lower 失效；看跌 OB 后续 Close>Upper 失效。严格比较，等号不失效。

没有复制 LuxAlgo 的区间极值 OB 选取、波动过滤、完整 BOS/CHoCH 或 FVG 阈值算法。基础检测结果不自动具备 Primary Target、有效 Sweep 或个人 setup 资格。

## 缺口

相邻输入 K 线须满足前一 CloseTime=后一 OpenTime。出现缺口后，新连续段重新积累三根 FVG 或摆动窗口。未终止的旧区域状态转为 Unknown；不把缺失时段解释成没有触及。

## 关键价格

采用 OKX 原生 1D / 1W（UTC+8，周一开始）。仅显示对应的前一日、前一周已确认高低；当日开盘只使用当前对应日线的 Open。缺少对应周期时省略，不回退到更早一天。

## 首次观测进入

区域边界包含端点。先有区外样本，再有区内样本，才产生首次到区。

- 关注区已启用且尚未触发。
- 当前价格时间严格递增；价格为正。
- 实时样本相对处理时间不得过期 30 秒或超前 5 秒。
- 前一个样本不得早于当前关注版本启用时间。
- 实时连续观测间隔最多 30 秒。
- 演示模式显式使用 300 秒收盘观测间隔；不会模拟逐笔触及。
- 断线后第一条样本重新建立基线。REST 可能漏掉请求之间的触及。
- 唯一事件键与数据库事务保证去重和重启一致性。

## Observed-Taker-CVD/1.0

- 来源：OKX 公共 `trades`，分别订阅 BTC-USDT 和 BTC-USDT-SWAP；包含接口提供的普通与 ELP 源消息。只统计指定品种，非跨交易所汇总。
- `buy` 是主动买方，`sell` 是主动卖方。现货 `sz` 为 BTC，永续 `sz` 为张数，乘当前 API 返回的 BTC 面值；拒绝未知或非 BTC 面值。
- `sz` 已是聚合数量，`count` 只记录撮合笔数。保留 `tradeId/count/source/seqId/ts`，不用可能重复的 seqId 去重。
- 按品种 + 最后成交 ID 去重。内容相同的重复消息跳过，内容冲突停止该段。新聚合的 ID 范围不得与上一条重叠，成交时间不得倒退；不假定 ID 跳号就证明遗漏。
- 两个订阅确认后开始接收；起点记录每个品种第一条实际收到的成交时间。短暂缓冲的首条成交可能略早于本地订阅确认时间。
- 每段累计 CVD = BuyBtc − SellBtc；首笔之前未采集历史未知，不补成零数据点。连接、重启、模式恢复分别分段，不按日/周自动重置。
- 成交相对接收时钟不得过期 30 秒或超前 5 秒。连续成交观测间隔超过 30 秒保守地结束段；这不单独证明交易所漏发。
- 每分钟储存最新累积值与该分钟买卖数量，Timestamp 是最后一条成交的时间，防止把后来的完整分钟值画到分钟前端。新成交会更新进行中的点。
- 每秒原始成交、最新 CVD 点和段汇总原子提交；视图仅使用已提交快照。正常关闭提交尾批，异常退出最多丢失未提交尾批，恢复不跨停机续算。
- 1m/5m/15m 显示各段各时间桶最后观测值，累积锚点不随显示周期改变。不同段采用不同图表序列，缺口不会连线。

## OI / 原生单位

`GET /api/v5/public/open-interest?instType=SWAP&instId=BTC-USDT-SWAP`，每 10 秒请求。保存 `oi` 张数、`oiCcy` BTC、`oiUsd` USD 和 API 数据时间；不使用本地报价重新估计原生 OI。相同 API 时间去重，数据超过 30 秒显示过期。图表按 API 时间采样，时间间隔超过 30 秒分段，缺失样本不插值。

OI 是未平仓合约规模，多空配对存在；增加本身不确定主动资金方向。美元名义量同时受币价影响。

## 订单流证据与导出

到区和记录时快照带当时采集段与订单流。导出每段当前汇总与最近 500 条原始聚合消息，明确完整汇总与局部明细的不同覆盖。演示订单流由独立确定性公式生成，不写入实盘订单流表。历史 OHLCV 不能还原真实主动买卖；本版本未提供完整历史成交回补或历史订单流 replay。
