# 行情解读 V0.2.5

入口为行情雷达的「行情解读」。生成时冻结当前数据和截止时间，窗口为最近 15 分钟或 1 小时，结束点为最近已收盘 5m 边界。它整理可核对的证据和条件；没有调用大模型或微调模型，没有自动下单。

## 位置、反应与订单流

1. 日线 / 4H 最近三根连续收盘的相对变化，仅用于背景。附近的人工关注区优先，其次 1D/4H 和其他 OB/FVG；区域已知时间不能晚于截止点。当前距离不超过 0.2% 才纳入，远处区域不作为本次反应依据。
2. 自动图层仍隐藏已使用区域。仅本次分析窗口内刚回访且未填满/失效的区域可作为“本窗口已回访”的解释证据；不重新标成未使用。删除的关注区和未来区域排除。
3. 最新 5m 刺穿前二十根区间高低点后收回，标为清扫 / SFP 参考候选。左右各两根已收盘确认摆动点，最新收盘穿越，标为参考 N2 结构破位。两者不能替代个人有效 MSB/SFP 规则。
4. 价格从窗口第一根 5m 开盘到最后一根收盘比较。CVD 使用这一窗口全部已收盘共同分钟的 Delta；缺分钟或换段就不确认整个窗口，不能仅比较两个端点。主动买卖差 / 总成交量用于区分方向强弱。
5. OI 使用原生 BTC；窗口起点、终点和中间必须覆盖。Coinalyze 使用所有所选线性永续共同收盘的 OI，公共源只用 OKX，端点最多容许 30 秒偏差，中间间隔最多 30 秒。不把 USD OI 的价格变化误读成持仓增加。
6. 加入完整且当前的日/周/月近似 VWAP 和可见、完整的固定范围分布，用作位置描述。

## 条件性解释

- 价格变化超过 0.05%、成交差超过总量 5%、OI 变化超过 0.1% 时用于描述方向。固定阈值尚未校准为用户个人交易规则。
- 价格、现货和合约成交同向：描述为上涨/下跌伴随同向主动成交。OI 增加只说明净新增未平仓合约，不识别多空。
- 价格与合约同向、现货不跟随：列出合约成交支持和现货分歧，不能直接证明“合约推动”。
- 价格上涨/下跌但 OI 减少：与净减仓相符，不直接认定逼空、平多、清算或新增资金。
- 价格与现货成交反向：列出“吸收可能，需验证”，不直接认定吸收或未来反转。
- 到看涨/看跌区域：输出守住/收回边界及局部结构观察条件，持续收盘越过相反边界时撤回对应假设。

至少价格新鲜、完整窗口价格、两类完整成交量窗口和 OI 都齐全，才输出窗口行情性质；高周期、结构和目标缺失另列。没有完整证据时输出“证据不足”。不自动给开仓/止盈/止损点位，也不虚构概率。

## 数据来源与边界

没连接 Coinalyze 时，用 OKX + Binance 共同覆盖的公开主动成交；首次启动后需要时间积累完整窗口。配置 Coinalyze 后优先该提供方，三分钟未更新、请求失败或未来获取时间会暂停订单流确认，不悄悄改用另一来源。图表可以手动看公共采集，分析快照独立标出使用的提供方。

Coinalyze 的标准 API 提供每市场 `v` 与 `bv`，本项目据真实主动买量计算 `Delta=2×bv−v` 并累计；没有直接抓取其网页“全市场 CVD”，也不用 K 线涨跌猜主动买卖。必须核对支持范围、单位和历史覆盖。当前真实账户联调待用户 Key；隔离 HTTP 测试验证的是格式、时间、单位筛选和缺失处理。

参考：[Coinalyze 官方 API](https://api.coinalyze.net/v1/doc/)、[提供方 OI 口径](https://coinalyze.net/blog/aggregated-open-interest/)、[本项目订单流规则](ORDER_FLOW.md)。
