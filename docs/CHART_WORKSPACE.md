# 图表工作区 · V0.2.4

程序启动即连接实时 OKX，不再提供演示入口。左侧宣传文案和图表下方的自动区域价格表已移除。

## 在图上建立关注区

1. 点击 OB / FVG 区域或对应标签，图上高亮这个区域，上方显示名称与价格范围。
2. 点击「加入关注」，补充关注原因并保存。来源区域、价格范围与时间位置一起保留。
3. 选择「矩形」，在图中点击两个角点；选中后点击「加入关注」。矩形会转为一个关注区，原绘图与新关注区在同一事务转换，避免重叠对象与重复关注。
4. 水平线也可转为关注区，默认上下各 25 USDT 是可编辑的起始宽度。
5. 趋势线也可加入关注：两个时间/价格端点确定斜率，关注带向未来延伸。填写「关注距离」，例如 25 表示动态线价上下各 25 USDT。图上拖动或调整端点会建立新版本。

关注区仍记录首次观测进入：先在区外，随后观测在区内。进入后查看当时 K 线、现货/永续 CVD 与 OI 快照，按自己的规则判断反应。当前没有自动判定 SFP/MSB 或自动下单。

趋势线使用 `FirstObservedTrendApproachOrCross/1.0`：连续两次有效观测从关注带外靠近，或相对动态线价换侧时记录一次。直接跨过整条带也可识别。保存、启动或断线后的首笔观测不补造事件；同版本首次事件后可编辑建立新版本。事件冻结端点、宽度、两次观测以及触发时的实际动态边界；向下延伸至非正价格后不触发。

## 绘图与选择

「选择」「矩形」「水平线」「趋势线」「成交量选区」位于图表上方。矩形与趋势线点击两个端点，水平线点击一个价格。选中绘图后，拖动内部移动，拖动端点调整。

Esc 取消未完成绘图；选择对象后点击「删除所选」，或在图表聚焦时按 Delete。刷新和重启保留已保存绘图，删除不会恢复。

「图上对象」可以定位当前图层中的对象；关注区卡片和成交量选区卡片也有「定位」操作。自动区域只显示未回访状态，已触及、填补、失效或状态未知的区域不会作为可选候选出现。

## 多个成交量选区

选择「成交量选区」，点击开始与结束 K 线，预览并保存。可重复建立多个独立选区；每个分布与 VAH/POC/VAL 画在自己的时间范围内。

保存的选区分别列为卡片：可以切换详情、定位、勾选显示或删除。隐藏会保存显示状态；删除后刷新和重启不会恢复，其他选区继续保留。

选中图上的分布后，也可以直接删除或关注 POC。删除选区不删除既有位置引用、到区事件或交易快照；原始计算证据保留在本地，历史事件内容不改写。

计算仍是已收盘 5m 高低区间均匀分配近似，不是逐笔成交分布。算法与覆盖定义见 [价格与成交量参考](PRICE_CONTEXT.md)。

## 图表来源

使用 TradingView 的开源 Lightweight Charts 与独立绘图扩展。完整 Advanced Charts 绘图套件未接入；官方不向个人项目提供该库。参考 [官方产品说明](https://www.tradingview.com/free-charting-libraries/) 与 [Primitive 扩展接口](https://tradingview.github.io/lightweight-charts/docs/plugins/series-primitives)。
